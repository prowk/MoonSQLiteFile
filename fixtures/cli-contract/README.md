# CLI 历史契约

`v0.7.0.json` 和 `v0.8.0.json` 分别来自正式 tag 的隔离构建：

| tag | 提交 |
| --- | --- |
| v0.7.0 | `8a3a4c79ecd54c893604839f9136081289b8f21b` |
| v0.8.0 | `cf7bdc5d9c9dd808640190d7f6904be4a21de8f9` |

v0.8.0 使用 v0.7.0 的相同 22 个场景重新执行发布源码的 CLI，记录输出及退出码，覆盖全部 17 个命令。两个版本分别核对，不用当前输出替换历史预期。此目录的坏文件、空文件和已提交 WAL 仅供契约验证；普通合法样本位于上级目录。

对应核心生成接口在 `tools/api-v*.mbti`，异步导出、函数 arity 及原型在 `tools/async-api-v*.json`；v0.8.0 数据同样取自该 tag，保留既有基线。兼容新增需要代码审查，删除、签名、字段和枚举变化仍必须评估迁移。验证方式见[贡献指南](../../CONTRIBUTING.md)。
